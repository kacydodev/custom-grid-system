## Overview

Custom grid system based on Code Monkey's tutorial. Inspired by grid system from games such as Wasteland 3, Xcom.

## System Flow

The system flow for this grid system is as follows:

1. Initialization: The grid system is initialized with a specified width and height.
2. Grid Position Calculation: Each grid object is assigned a grid position based on its position in the grid.
3. Grid Object Creation: Grid objects are created and placed at their respective grid positions.
4. Grid Object Interaction: Grid objects can interact with each other and the grid system.
5. Grid System Updates: The grid system updates its state based on the interactions between grid objects.
